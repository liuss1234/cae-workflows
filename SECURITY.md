# Security Policy

## Supported content

Security fixes apply to the latest `main` branch and current GitHub Release. Historical tags and user-generated cases are not maintained as security-supported distributions.

## Reporting

Do not place credentials, private model data, customer files, host details, license material, or unredacted logs in a public issue. Report a suspected vulnerability through the repository's GitHub Security tab using a private security advisory.

Include the affected workflow, a minimal reproduction, impact, environment, and any safe workaround. Maintainers will acknowledge the report before discussing public disclosure or a release timeline.
