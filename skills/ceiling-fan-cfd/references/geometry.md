# 保形清理与缺陷定位

记录源哈希、单位、零件树、轴、体积/包围盒、叶片数量、吊杆径长、底壳极点和叶尖见证点。源体自交时不能以异常体积作守恒基准。

| 位置 | 可采用的处理 | 必需核对 |
|---|---|---|
| 内腔、封闭装配缝 | 外流模型局部填实 | 不外扩、不封真实通风路 |
| 叶根槽、小倒角 | 限定半径/高度恢复主面交线 | 外露叶型和安装角 |
| 底壳 | 原始解析面或精确截线回转 | r–z母线、极点、外形偏差 |
| 叶尖和前后缘 | 保留气动外形 | 截线、差集、见证点 |
| 吊杆 | 内部可实心，外形保留 | 实际CAD及网格径长 |

`removeSplitter()`仅消冗余分割，`makeSolid()`仅构拓扑，均不代替去倒角或自交核查。FreeCAD先valid/closed/正体积，再`shape.check(True)`保存BOP/PCurve诊断；脚本`cad_audit.py --input model.brep --output audit.json`在FreeCAD Python运行。STEP另开进程回读。

三个实际陷阱：

1. 沿轴半径闭运算和端部复制填充会生成额外平底圆柱；用原始精确母线恢复，核对真实极点，不能用减面数/网格成功证明保形。
2. 重复叶片有装配碎面时，仅在确认同型件后恢复副本；按原主曲面控制点求真实刚体变换，不强制等角布置。核对外露区域对称差，改动只限已填实叶根。
3. 原生BREP深度通过但STEP交换重新收紧参数导致InvalidCurveOnSurface：保留诊断并标候选，已验收原生可继续网格。FreeCAD/Gmsh均OCC，不当作独立内核证据。公差按实测参数偏差设定，禁止无依据整体放大。

补面需查面内/边界采样、面积、法向和邻接；B样条包围盒可能保守，辅以裁剪曲面/截线。新产品重新识别零件/面号。清理记录包含局部坐标范围、操作、理由、源/目标哈希、外形最大偏差、体积变化和未解决问题。
