# 来源与验证边界

来自七款不同尺寸与装配吊扇：保形清理、叶根填实、吊杆网格修复、多面体/棱柱层、QFlux双区MRF、2000步监测及成对交付。发布知识已脱敏，不包含客户模型、实测报告或完整流场。

真实项目经验包括：底壳被错误改平后恢复精确母线；CAD杆正常但网格重构失真；局部倒角导致棱柱层回缩；STEP与原生参数检查差异；区/接口/运动设置保存不完整；SSH进程未保活；旧结果及旧转速误选。

发布验证分层：

1. 无商业软件测试：初始化、参数/单位、角速度、检测面、宏渲染、监控、打包越界/篡改。
2. 真实既有网格只读：正体积、闭合、CAD体积差、层号面积匹配和原生质量。
3. 已安装QFlux API：对既有工程独立回读；未重跑的商业网格/求解不称为重新验证。
4. 新产品几何：仍需识别部件/外形与物理取舍，不保证任意STEP全自动清理。

软件版本、实际执行检查及限制见[发布验证记录](release-validation.md)。Python工具可迁移不代表商业API已跨Windows/Linux端到端验证。本技能不含声学、结构振动、瞬态叶频、叶片设计优化或标准认证。
