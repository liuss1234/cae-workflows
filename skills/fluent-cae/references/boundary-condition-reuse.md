# Fluent 边界条件复用

Fluent 的 `write-bc`/`read-bc` 可用于把已有算例的边界相关设置迁移到另一个算例，适合模型几何变化但工况设置大体相同的场景。

## 流程

1. 在源算例完成设置后，通过 TUI 执行 `/file write-bc boundary.bc`，将文件放在受控的案例目录。
2. 打开目标网格或 case，先完成网格检查和 `Scale`。不要假定 `.bc` 文件会修正长度单位或网格尺度。
3. 尽量让源、目标算例的边界区域名称一致；名称不匹配时，边界设置可能无法逐项映射。
4. 在目标算例执行 `/file read-bc boundary.bc`，然后逐项检查边界类型和数值。

## 读取后必须复核

- 边界类型、压力/速度/温度、湍流量和方向分量；
- 材料、物性、组分、能量和湍流模型；
- 操作压强、参考值、参考面积/长度和坐标约定；
- 目标几何的边界名称、法向、尺度和连通性。

复用设置减少重复输入，不等于两个模型物理等价。对新几何仍应重新定义与研究目标相关的参考量和验收指标。
