# Fluent 跨网格初场插值

Fluent 的 Interpolate 可将源网格的场变量写成 `.ip` 文件，再按空间位置映射到目标网格，适合网格无关性研究、局部加密和相近工况的初场迁移。

## 流程

1. 让源算例先达到可接受的候选状态，并记录网格、边界条件、模型、物性和收敛证据。
2. 在源算例使用 `File → Interpolate → Write Data`，选择需要的 Cell Zones 和字段，写出 `.ip` 文件。
3. 打开目标网格，完成 Scale、区域和边界检查；确认变量名称、单位和物理模型兼容。
4. 使用 `File → Interpolate → Read and Interpolate` 读取 `.ip`，观察控制台是否完成读取和初始化。
5. 在正式迭代前显示压力、速度和湍流量等初始场，再运行目标算例并重新检查残差、守恒、监测量和物理合理性。

## 适用边界

- 网格单元数量可以不同，但目标区域和变量必须有合理的空间对应关系。
- 大幅改变几何、边界类型、物性、模型或坐标系时，插值可能产生未定义、外推或不物理初值；应改用初始化或分阶段启动。
- `.ip` 只提供初始场，不是新网格的结果，也不证明网格无关性。
- 对比研究应保存源/目标网格哈希、`.ip` 哈希、变量清单和最终验收记录。
