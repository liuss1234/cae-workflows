# 发散诊断

发散指残差逐代上升或出现 NaN、负压力/温度/密度、速度/湍流量越界。先确认失败发生在哪个阶段，再按阶段排查。

## 首步即爆

首步或头几步就超限，通常是输入错误而非数值方法本身：

- 单位与尺度：网格坐标应为米。若建模用毫米导出成米，包围盒会放大 1000 倍，速度、压力和湍流量全部失真。先核对包围盒最小/最大坐标和特征尺寸，不要只改文件名。
- 介质与物性：密度、黏度、温度口径是否匹配；理想气体与不可压的设定是否和边界条件一致。
- 压力口径：压力入口/出口是表压还是绝对压，方向是否反了；参考压力是否与实际工作压冲突。
- 湍流量初值：k/epsilon 或 k/omega 初值是否为 0 或物理上不可能的值；入口湍流强度与长度尺度是否合理。
- 参考系与旋向：MRF/旋转域轴线、旋向、转速单位（rad/s 还是 rpm）以及壁面参考系是否写错。
- 接口/开口：接口是否真的配对成功，开口边界是否在回流位置被错误地当成了壁面或对称面。

先小步预运行，定位最早超限的单元位置和流向，再对照该处的边界类型和物性。

## 跑几步后发散

能跑一段再发散，常见原因是网格缺陷被流场逐步触发，或边界条件在迭代中失稳：

- 负体积/低质量单元：尤其在变形、动网格或棱柱层偏移后。先修几何和网格，不要指望降松弛救回来。
- 无边界层或层过薄：近壁 k/epsilon 或 omega 方程对首层厚度和 y+ 敏感，壁面附近残差先爆往往是层网格问题。
- 回流开口：出口附近出现回流时，固定边界值会造成质量回流放大的假象。先加长出口段或改压力边界，再看是否仍发散。
- 瞬态步长过大：CFL 过大、时间步与最小单元尺寸不匹配会在几步内发散。用速度/最小单元尺寸估算候选步长并记录。

## 数值保护与调试路径

逐项单因素试验，记录每一项的实际值和是否生效：

- 一阶迎风 → 二阶迎风（升级格式）在发散时先降回一阶，跑通后再升回。
- 松弛因子降低只对「能跑但振荡」有用，对「网格/边界错误」无效；先排除输入错误。
- 非正交修正、correctFlux、速度/温度上限等限制开关，记录触发次数、比例和位置。限制长期大量触发时，稳定残差不能解释为有效解。
- 初始场：用更稳健的工况或粗网格先算一个初场，再映射到目标工况；初场来源和哈希要记录。

NaN、负量或大质量不守恒的阶段保留原样作为证据，不覆盖成功网格，也不能纳入有效性能排名。
