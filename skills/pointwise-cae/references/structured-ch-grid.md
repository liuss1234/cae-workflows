# C-H 结构化网格

C-H 网格适合具有明确主流向和尾迹方向的二维翼型教学案例。核心不是记住某个节点数，而是保持块拓扑、边界对应和尺寸过渡可解释。

## 建议流程

1. 从已检查的翼型曲线创建上/下表面域，明确前缘、尾缘和远场边界。
2. 构建包围翼型的 C-H 拓扑，使 C 方向沿前缘绕过翼型并在尾缘下游展开，H 方向连接到外场或尾迹端。
3. 在前缘、尾缘、壁面法向和尾迹区域集中节点；沿远离翼型方向平滑增长。
4. 创建块连接和边界条件映射，检查索引方向、周期/连接关系及法向。
5. 检查最小单元尺寸、增长率、尾缘拥挤、网格正性和尾迹分辨率，再导出目标求解器格式。

## 物理复核

若研究阻力、分离或换热，先按湍流/壁面模型估算首层高度和层数，再决定拓扑。C-H 结构只是离散布局，不能替代 y+、网格收敛和气动力系数验证。
