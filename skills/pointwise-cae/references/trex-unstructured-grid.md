# T-Rex 非结构网格

T-Rex 路线适合需要更灵活适应复杂边界的二维非结构网格。操作重点是壁面间距、边界层参数、局部加密和最终实际层覆盖。

## 建议流程

1. 设置翼型壁面和远场节点间距，先确认尺寸分布不会在前缘、尾缘和远场处突然跳变。
2. 生成非结构核心网格，并把翼型边界指定为需要边界层推进的边。
3. 按目标 y+ 设定第一层高度、增长率、层数和总厚度；这些是工况参数，不从教学案例盲目复制。
4. 对前缘、尾缘、间隙和尾迹设置局部加密，观察 T-Rex 层是否碰撞、截断或在高曲率处失败。
5. 检查实际层数/厚度、负体积、偏斜、尺寸跳变和外场边界覆盖；把失败位置写入网格报告。

## 失败处理

层推进失败时，先检查几何法向、短边、局部尺寸、层总厚度和相邻边界间距。若必须减层或缩薄，应记录原因和对近壁分辨率的影响；不能静默退化为无边界层网格后宣称完成。
