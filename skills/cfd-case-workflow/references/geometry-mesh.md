# 几何清理、流体域与网格

## 清理位置可追溯

1. 记录输入文件、单位、实体数、包围盒、体积和关键最小间隙。对源文件只读，清理在副本中进行。
2. 区分显示精度造成的缝线、真实设计/装配间隙、不缝合开边、重叠体和重复面。视觉上有缝不代表需要封堵。
3. 通孔、盲孔、槽孔、通风孔及入口通路逐个按物理作用取舍；圆角/倒角按压降、分离、应力或接触传热影响判断。删除时记录部件、位置、尺寸、操作、理由和可能误差；用户要求全部保留则保留并相应细化网格。
4. 修复后检查实体有效、壳封闭、最小边、薄片、碎面、布尔前后体积/包围盒。另设关键特征见证点、局部体积或截面核对，避免融合后小零件消失。实体有效不证明原始特征完整保留。

Blender 适合三角面清理与可视化；工程 STEP 的实体布尔、微小间隙控制和域抽取优先 FreeCAD/OCC。不能用“Merge by Distance”全局焊接把设计缝隙一并消除。

## 域抽取

- 内流：封入口/出口截面，构造湿空间或用包络扣除固体。检查连通分量、死腔和每路最小通流截面。
- 外流：建立足够远场，扣除目标实体；地面、侧面和尾迹布局根据流动方向定义。对阻塞比和边界影响作工程判断，尺寸倍数不是固定万能值。
- MRF：旋转包络完整包住叶轮，扣掉固体，与静止流体体积互斥且接口贴合；不要让旋转区域穿入静止实体。
- 运动体/重叠网格：分别保存背景与运动体网格，按全轨迹检查重叠范围、孔切除、供体覆盖和运动体与背景壁面间隙；不能把两套独立网格误并成一个共形域。
- CHT：流体和真实固体体积都保留，各自无重叠。接触面真实贴合或显式接触热阻，不能把断开的两层面当作自然耦合。

## 面和区域命名

CAD 导入/布尔/fragment 都可能改变 face tag。依据域邻接、形心、法向、面积、包围盒及已知截面重新映射。分类有歧义时报错并给出候选面，不能把未知面静默归为 wall。

名称例子：`inlet`、`outlet`、`wall_duct`、`wall_rotor`、`wall_shell_external`、`interface_fluid_side`、`interface_solid_side`。多入口/出口加编号或含义；支路测流面不一定是边界，可是内部切面/内部面集。

## 网格与格式

- 壁面、窄缝、弯头、分支、尾迹和热边界层局部细化。网格策略随目标量变化，不用某个旧案例的尺寸套所有模型。
- 壁面摩擦/换热敏感问题设计棱柱层、首层厚度、增长率和目标 y+，求解后复核实际 y+ 与选定壁面处理一致。纯演示可用无棱柱 TET，但必须注明精度限制。
- `mesh_export.py` 只接受 TET4/TRI3，校验所有实体和 Physical Groups 完整归属。棱柱、HEX、高阶/混合网格应采用其真实单元格式/适配器，禁止过滤不支持单元后仍交付。
- 结构化六面体网格需在可控的多块拓扑/网格工具中生成，并通过对应原生格式和适配器传递；本交换器不适用于结构化网格，也不能生成 overset 插值/孔切除元数据。
- MSH 2.2 ASCII 可作为目标导入兼容备份；CGNS 推荐用于区/边界完整传递。不能因为 MSH 能打开就推定 QFlux 全部分区恢复。
- 坐标实际 mm→m乘0.001，面积乘1e-6、体积乘1e-9；保存后核对 bbox、已知尺寸和体积。STP/FCStd 可以 mm，网格 m，交付中写清楚。
- CGNS 库用标准 C API 写入，h5py 只独立回读；普通 HDF5 可打开不证明 CGNS 合规。在 Windows 先 import h5py，再加载厂商 CGNS 库，避免同名 HDF5 DLL 抢占依赖。

## 基础质量报告

列出节点/单元类型与数量、负/零体积、非流形面、边界漏标/重复、最差单元位置、最大值与p99。阈值按目标求解器、单元和物理选取，不以单一阈值定义所有网格好坏。

四面体交换器的质量定义：

- `skewness = 1 - V/V_equilateral_same_circumsphere`，等边四面体为0，接近1较差。
- `aspect_ratio = sqrt(2/3) * longest_edge / minimum_altitude`，等边四面体为1。

这些与 QFlux face skewness 的定义可能不同，报告中不要混称。QFlux 本机 `qxZoneMng.getZoneFaceSkewness(zone)`、`getZoneCellAspectRatio(zone)` 可按需实读并报告该软件定义；必要时查厂商手册。基础质量通过不证明网格收敛。用户排除网格收敛研究时不强行增加三档计算。
