# 验收与真实场后处理

## 网格/几何

确认有效且单连通的流体 CAD、正 Jacobian、没有重复单元、边界覆盖完整、内部面两侧匹配。模板保留建网格时的坐标/单元连接 mesh_arrays.npz；CAD 体积和网格体积独立比对。

模板的长宽比为最长边/最短边，不等同于所有软件的体积等效 aspect metric。skewness 使用等角度定义；零值仅因所有轴对齐长方体面角为90°。报告最差值、P99、位置，不将高长宽比自动当作合格。网格首层全厚0.3mm不等于首单元中心距/y+。

## 原生工程

预期名称/type、所属网格区、体单元/节点数必须一致。单区水力管网并不需要旋转域或人造 interface；其他物理问题自行建立必要分区。默认边界数 `4+3N`。

## 计算完成

run/finished.json exitCode=0、实际进程结束和完整 DAT 是正常完成证据。程序退出0也可能因达到迭代上限而未收敛。

默认后处理阈值：所有输出的连续性/速度/k/omega 残差 ≤1e-6；质量不平衡 ≤0.01%；最后200次压降极差/最终压降 ≤0.1%。阈值可在 workflow 配置，不能降低阈值只是为了宣称完成。求解器原生判停项可能仅启用了连续性/动量，最终后处理额外核查湍流残差。

若边界最后记录与 DAT 编号不一致，只接受文档说明的残差收敛+1例外。图表应标明阶段、格式和是否收敛；不将最终图混用初始场。

## 支路流量

官方 VTU 坐标逐点核验，HEX8 单元逐单元比较节点集合，确认单元字段顺序正确。模板在冷板25%、50%、75%长度附近选择真实共形内部面，从两侧单元中心 Ux 线性重构到面，以法向速度乘面积积分。

这不是求解器压力修正后的守恒面通量；必须同时输出三截面流量与总积分相对入口误差，保留误差，不强制归一化。CSV 的百分比分母是重构总流量；均流偏差相对全部支路实际重构均值。

| 指标 | 定义 |
|---|---|
| CV | population std(Q_i)/mean(Q_i) ×100% |
| 最大偏差 | max(abs(Q_i/mean(Q_i)−1)) ×100% |
| 极差/均值 | (max(Q_i)−min(Q_i))/mean(Q_i) ×100% |
| 质量不平衡 | abs(m_in+m_out)/abs(m_in) ×100% |
| 压降 | inlet/outlet 面积平均静压之差 |
| 单工况水力阻抗 | Δp/Q，非完整阻力曲线 |
| 水力功率 | Δp Q，不含泵效率 |

圆管/真实冷板/其他流向/非共形网格需重建截面积分，不套用 x 面或矩形水力直径。可用求解器原生内部面通量时优先核对，不能以均分假设代替 CFD。

云图绘制 Y=0 实际流体面，保留管路之间空白，不做跨实体空隙插值。低 Reynolds、过渡区、未验证 y+、一阶数值扩散和缺少网格收敛验证均在报告说明。

## 打包

先核对 QFX/DAT 配对、收敛、名称和日志；白名单包括脚本、CAD、网格、实际场、监测、配置和结果。不包含无关目录、临时并行碎片、Python/DLL、SSH 凭据。包有逐文件 SHA256 和 ZIP CRC；旧阶段标注历史，不与最终工程混淆。结果未收敛时仅可显式 `--allow-incomplete` 打包阶段文件并说明。
