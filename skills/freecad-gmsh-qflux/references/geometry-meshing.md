# 几何处理、流体域与网格

## 从实际模型开始

使用当前 FreeCAD 文档时，先查询文档名、保存路径、可见对象及最终实体；用 `document.saveCopy(new_path)` 保留独立输入，不以显示截图推断拓扑。STEP 输入采用 OCC 实体，记录单位证据和特征尺寸。

对零件记录：有效性、壳体封闭性、实体数、体积、面积、包围盒和连接关系。几何清理报告应明确“哪个零件/面、原问题、做了什么、修改前后数值、保留什么”。

孔、槽、圆角、倒角及设计/装配间隙必须结合用户要求和流动作用决策。小尺寸本身不是删除理由。典型处理：

| 情况 | 处理与验证 |
|---|---|
| 同一转子内部重叠 | 合并实体并移除内部冗余面；验证外部湿表面与占据体积 |
| 无物理意义的小面/共面边 | 适当使用 `removeSplitter()`；之后重新验证拓扑与体积 |
| 真正的泄漏/叶尖间隙 | 保留并量化最小距离，据其决定局部网格尺寸 |
| 无关外部安装孔/外角 | 仅在研究域外且用户允许简化时处理；核对计算域内固体对称差 |
| 疑似重复面或细缝 | 先区分显示网格裂纹、曲面拼缝、实体间隙与非封闭缺陷，再选择缝合或布尔修复 |

七叶风扇示例简化了圆管流道之外的安装孔和外角，并检查流道内固体占据体积未变；这不是所有模型都可以封孔/去圆角的规则。

### 深度检查、曲面兼容与半成品

基础 `isValid()` 与 `isClosed()` 不检查全部布尔自交风险。对重建、缝合、去内部面与复杂样条模型，保留 `shape.check(True)`/BOP 诊断、正体积和新进程 STEP 回读结果。FreeCAD Python 先 `import FreeCAD` 再 `import Part`，避免部分发行版的模块初始化失败。

曲面面积/形心异常到远超零件尺度时，先定位面与底层曲面/PCurve，不用异常体积作守恒指标。CAD 样条 bbox 可能保守，结合采样外形、截面、边界点及精确距离检查。FreeCAD 与 Gmsh 常同用 OCC；共同失败说明该导入链路异常，不证明 ANSA 等原生模型必然有错。

有效补面也可能越界；须核对面内采样、轮廓、面积、曲率/连续性与相邻边。禁止把粗直纹叶根或顶底面相交包络当原叶型的无损清理。面编号只能用于本次文件；旧版本的 Face 编号不可移植。用户参考版用于确定保留外形和衔接意图，仍单独检查。

每个清理位置给部件/坐标/几何签名、处理前后截面或局部图、偏差与状态。候选失败就明确给半成品路径及具体失败位置；不得因为面数下降、界面显示正常或外壳封闭便宣布完成。

## 流体域与旋转区

1. 基于已确认的内流/外流类型建立包络，扣除固体得到总流体体积。
2. 按转子真实外表面与静止部件间距放置接口。B 样条的包围盒可能保守；贴近部件的接口使用精确距离/极值检查，避免制造薄流体层。
3. 分割流体区并检查：每区有效封闭且正体积、区域交集为零、区域并集覆盖总流体、总体积和一致。
4. 对每对接口检查面积相等、重合面积、相反外法向、相邻区域与剩余间隙。

旋转域可以延伸至圆管内壁；此时该域内的管壁以及静止电机表面必须在绝对参考系保持静止。叶片/轮毂壁面相对旋转参考系静止。不得按所属网格区名称自动把所有壁面设为旋转。

参考圆柱 `rotor_envelope` 与剖切显示对象只用于审查。网格输入必须是已扣除固体的真实流体体积。

## 面标签跨软件传递

FreeCAD 中保存每个边界的区域名、面积、形心和面名。STEP/Gmsh 导入后实体编号可能重排；若使用共享拓扑，先 fragment，再用邻接关系和几何签名恢复名称。一个候选匹配到多个面，或没有候选时，停止该次映射并报告歧义，不能静默归到 wall。

Gmsh 必须显式有三维物理组和二维物理组，所有流体边界均被覆盖；共享内部接口在 MSH 中可能只存一组面，CGNS 则要按相邻区域生成各自的外向面。

## 网格与检查

示例使用 Gmsh 4.14.1 的一阶四面体及三角边界。附带转换脚本不支持混合单元、二阶单元或棱柱层；遇到其他单元类型需要新适配，不能降阶后仍称无损转换。

通过正体积、Jacobian、重复单元、非流形面、边界覆盖、接口邻接、CAD/网格体积偏差检查后，再报告 minSICN、非正交角、边长比等质量分布及最差单元位置。阈值与求解器和物理模型相关；不以单一固定 minSICN 宣称所有 CFD 计算可用。

本例无棱柱边界层。若目标为壁面摩擦、压降、扭矩或换热，需按工况和壁面处理确定首层厚度、层数、增长率及目标 y+。网格无关性研究按用户范围决定，未做时说明限制；用户明确排除时不额外增加三档计算。没有工况时交付初始网格及未完成项。

## 进度与恢复

每个耗时阶段保留 JSON 进度/日志。查看日志与进程状态后决定是否继续等待；不要在无新证据时反复启动相同的大型布尔或网格命令。可用既有经过验证的中间模型继续下游，换目录保存新结果。
