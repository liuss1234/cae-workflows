# FreeCAD → Gmsh → QFlux CFD 前处理

将 CAD、网格物理分组和 QFlux 内实际识别的对象对应起来。交付依据是落盘后独立回读的尺寸、名称、归属和面数，不以命令返回成功或软件启动替代验证。

## 按任务选择资料

- 首次运行或换电脑：读 [环境与软件职责](references/environment.md)，复制 `assets/environment.example.json` 到仓库外，填写本机路径后执行 `scripts/probe_environment.py --profile <配置文件> --check-imports`。不要将一台机器的路径和 Python ABI 当作其他电脑的默认值。
- 建模、几何清理、流体域或网格生成：读 [几何与网格流程](references/geometry-meshing.md)。涉及真实工况的网格策略时，结合可用的 `cfd-preprocessing` 技能；本技能自身包含必要的几何和命名验收约束。
- 米制导出、QFlux 中只显示一个区或边界缺失：读 [QFlux 交付与检查](references/qflux-handoff.md)，使用通用检查工具 `scripts/qflux_handoff.py`。
- 复现本次风扇或适配脚本：读 [七叶风扇示例与运行方法](references/fan-example.md)。`run_fan_example.py` 是这份特定风扇的运行器；其他零件需要重建零件映射、流体域方案及边界清单。

## 工作约定

1. 从当前文档建立独立快照，记录模型坐标单位、研究范围和需要保留/删除的几何特征。既有项目参数优先；未知转速、流量、压力、湍流与 y+ 不补猜测值。默认交付 m；输入单位必须有几何尺度或 CAD 元数据证据。
2. 使用 FreeCAD/OCC 处理 STEP/实体布尔与封闭性。孔洞、槽、圆角、倒角和装配间隙按流动影响及用户指令决策；不能把“有缝”直接等同于坏几何。记录修改位置和体积/面积/最小间隙变化。
3. 旋转流体域是包络扣除真实固体后的体积。参考包络与显示剖切体不进入体网格。检查区域无重叠、无遗漏、接口两侧面积一致和法向相反。
4. 在 Gmsh 中显式创建 Physical Volume / Physical Surface，并检验全部流体边界均有名称。导入 STEP 或布尔运算后不沿用旧面编号；按邻接、面积、形心与曲面性质恢复标签。
5. 默认保持已有网格，只在需要时重划。先检查正体积、重复单元、非流形、边界覆盖和接口邻接，再报告最差质量与位置。没有边界层时明确用途及限制。
6. 针对本机 QFlux 的多区交付，优先显式多区 CGNS，再保存原生 QFX。MSH 2.2 ASCII 可解决格式兼容问题，但“可解析”不代表所有 physical groups 都被恢复。
7. 将预期区域/边界清单与 QFlux 管理器实际读数逐项比较，保存后在新进程回读。输出全部名称、面数、所属网格区和 m 制尺寸。一个流体求解计算域可以包含多个网格区，不人为拆成多个求解计算域来增加显示数量。

## 不混淆三种完成状态

| 状态 | 必要证据 |
|---|---|
| 边界识别完成 | QFlux 实际名称集合、归属、边界面数与导出清单一致，QFX 回读保持 |
| 接口连接完成 | 实际静止侧/旋转侧关系与持久化设置可核查；只设 Interface 类型不算配对成功 |
| 旋转工况就绪 | 旋转网格区、轴、原点、转速/方向和壁面参考系设置正确；转速未知时只能交付几何/网格 |

若 `interfaceGroup` 导出为空，不推断接口已经配好，也不推断该版本绝对无法耦合；报告当前 API 能验证到的状态。不要为绕过接口错误擅自开启能量方程。

## 工具与范围

- FreeCAD GUI 用原生宏/Qt 事件循环连续展示步骤；批量 OCC 运算可交给 FreeCADCmd，并定期读进度。无用户要求时不人为逐步暂停。使用现有 GUI 时先确认目标文档。
- QFlux Python API 的独立进程不等于控制正在打开的 GUI。只用已安装版本的公开 API/类型声明；GUI 交互在相应工具可用时再使用 `computer-use` 技能。缺少桌面操作工具时不要伪称完成了界面点击。
- Blender 仅在三角网格修复、可视化等任务实际需要时加入，不是这条已验证 BREP/CGNS 工作流的必需依赖。
- 软件和计算在用户指定位置运行。本机已满足需求时不再寻找远程连接；此技能不自带 SSH、凭据或外部传输。
- 模板脚本复制到新工作目录后运行，保护原始模型和已交付文件。处理失败保留日志/中间结果并定位阶段，避免无变化重复尝试。

## 交付

交付清理记录、CAD/流体域、命名清单、网格质量、米制 CGNS/QFX 和实际导入/回读报告。按当前任务范围选择所需产物，指出接口、旋转工况、边界层和网格无关性尚未完成的部分。可用新工程路径正常启动 GUI 供用户查看；只有已读取的文件/窗口信息才作为打开成功证据。
