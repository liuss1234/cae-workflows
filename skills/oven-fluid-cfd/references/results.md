# 发散、逐出口流量与误差

## 四种状态分别判断

1. 调度：作业号、状态、退出码、时间、核数。COMPLETED不能证明数值收敛。
2. 求解：原生迭代和全部方程残差、NaN/Inf、Divergent等报错；区分字段NaN和残差文本为有限。M04有限残差行之后原生k NaN，是明确发散。
3. 数值验收：预定残差门槛、所有开口同步守恒、压力和逐出口流量稳定、方向/量级合理。
4. 结果可用性：保存完整场、重组合并、工程匹配、官方回读、y+及研究目标相容；未做网格无关性/实验对比就不能给精度声明。

M08约700步后残差反弹，887步停止：没有原生NaN报错，但未通过收敛和稳定性，不能称成功；也不能把它写成已确认NaN发散。守恒小仅说明质量收支接近。

## 同步窗口与统计口径

使用原生 `air-mass_<boundary>.dat`，其中air是实际region名；不要把体积通量当质量通量。解析#iter/#iteration头部，略过不完整尾行；所有入口和出口取共同迭代的最后N步，核对恰好连续N步。不能把入口886步与某出口885步凑成一次守恒。

约定外法向为正：入口负、出口正。检测每个出口窗口的负净流量和异常入口方向；反向流窗口不能按正常均匀分流通过。已知常密度时 `Q_i[m³/h]=m_dot_i/rho*3600`；变密度场不得用单一rho假转换，直接读取原生体积通量并单独做质量守恒。

| 指标 | 定义 |
|---|---|
| 均流偏差 | (某出口窗口均值−全部出口窗口平均值)/全部出口窗口平均值×100% |
| 入口均分偏差 | (某出口均值−入口流量/出口数)/(入口流量/出口数)×100% |
| CV | 出口均值的总体标准差/出口总体平均值×100% |
| 守恒误差 | abs(所有开口有符号质量通量之和)/max(总流入,总流出)×100% |
| 窗口波动 | (窗口最大−最小)/abs(窗口均值)×100% |

同时列窗口平均通量守恒、逐步最大守恒误差和相对指定入口的净误差，防止巨大非物理回流使分母变大掩盖发散。默认历史筛查0.1%守恒、0.5%流量/入口压力波动、1e-5全部方程残差，均须依新项目定义；压力均值接近0时改用约定绝对波动判据，不把分母钳大后宣布稳定。

脚本 `analyze_outlets.py`不推定全工程通过。输出JSON和CSV、来源监控文件SHA256、共同迭代区间、窗口完整性、反向流及状态。缺数据/NaN/Inf失败退出；窗口不足或反向流会给诊断但passed:false。将结果与原生残差、网格报告、调度和完整场状态一并解释。

## 交付结构

技术记录按“域范围与简化→边界/物性/数值方法→网格及实际层覆盖→求解状态与残差→每排流量/守恒/波动→限制”组织。分流均匀性、守恒误差、网格误差和实验误差是不同概念。本例只完成前两项诊断，不能据两套失败/未收敛网格估离散误差。

原始场未独立读回时只报告保存证据，不生成伪云图或拿初始场当结果。公开技能附匿名真实摘要和明确标注的合成测试；私有几何、截图、原始监控和QFX/DAT不入公开仓库。
