# STAR局部命名、切割体网格与真实层覆盖

## 命名及交换

将计算CAD湿面唯一分配到入口、出口和壁面组。风嘴局部分别命名为 `wall_nozzle_<label>_shell`、`wall_nozzle_<label>_holes`、`wall_nozzle_<label>_baffles`；另设供风连接、供风腔导流板、孔壁和主壁。`<label>`由当前项目填写，不预置真实部件枚举。挡片、孔壁和主壁不能仅靠总wall组调层。

`regions.json`是物理语义；`checks/cad_boundaries.json`在私有案例中记录实际湿面索引/签名、面积、包围盒和体积。面号绑定BREP SHA256，换STEP后重匹配。OCC保形离散的弦高与角度按项目确定，验证闭合、共边方向及相对体积误差。交换三角面不是体网格；公开包不附真实几何统计与离散参数。

## 参数填写与层控制

使用表面重划 + Trimmer + Prism。全局尺寸、局部表面尺寸、窄缝核心尺寸、棱柱层总厚度和最小尺寸均按当前模型填写，公开模板留空。

| 壁面类型 | 历史请求层数 | 项目需填写 |
|---|---:|---|
| 风嘴主壁/供风连接 | 2 | 表面目标尺寸、总厚度、最小尺寸 |
| 孔壁/挡片 | 2 | 表面目标尺寸、总厚度、最小尺寸 |
| 供风腔导流板 | 2 | 表面目标尺寸、总厚度、最小尺寸 |
| 供风腔孔壁 | 1 | 表面目标尺寸、总厚度、最小尺寸 |
| 其余供风腔壁面 | 1 | 表面目标尺寸、总厚度、最小尺寸 |
| 入口/出口 | 不生成棱柱层 | 表面目标尺寸 |

上述层数为网格方法参数，不表示产品部件数量。增长率历史设置为1.2；导流板局部BOTH邻近搜索为1.5 points in gap，其余区域按需要关闭邻近加密，避免无关装配细节触发网格膨胀。历史棱柱层minimumThickness=1%、reduction=1%、nearCoreAspect=0、gapFill=40%。该STAR版本gapFill严格小于50%，设50会失败。先用独立合成小块测试API、枚举、边界控制及导出，再运行整模；小块通过只证明控制可用。

窄缝厚度方向2–3单元是历史用户初始意图；必须用最终截面数单元，不能因设置了2层就声称全窄缝满足2–3单元。首层与y+须结合壁面处理另行验证，层数/总厚度不能单独确定精度。

## 宏与版本适配

`scripts/render_star_macro.py`将案例参数渲染成 `assets/MeshOven.java.in`。输入必须是已命名、以m存储、闭合的多solid ASCII STL；宏导入前检查名称清单，生成新版本目录，运行后保存SIM、原生质量、逐壁面Layer Number/First Layer Height CSV和完整CGNS。它不自动启动STAR。源UTF-8；目标批处理若要求GB18030，显式 `--encoding gb18030`，文件名与public class一致。模板来自18.06实测API；渲染后的通用宏尚需在目标版本编译，不能视为跨版本兼容承诺。

## 网格审计

`check_trimmed_mesh.py`检查单流体区的NGON/NFACE，全部命名面非空且唯一；内部面两侧引用相反，外面仅被单侧引用；面闭合、单元正体积、CAD体积/包围盒一致；与STAR原生质量报告单元数一致。该版本针对STAR多section NGON导出，不是任意CGNS转换器。

用壁面面心匹配原生实际层号，按CGNS真实面面积加权。拒绝重复/多义面心和未匹配面；列出缺层位置并检查真实截面。点数覆盖不能冒充面积覆盖，只有请求参数不能证明生成成功。

历史工程筛查门槛包括SkewnessAngle<85°、FaceValidity≥0.95、正体积、relative closure<1e-6、CAD体积差≤0.5%、各壁面完整请求层数面积≥95%。CAD到网格包围盒容差及同网格跨软件导入容差由当前项目声明并填写，不公开旧项目长度值。这些是工程筛查规则，非统一标准。M04/M08均未通过整体质量，最终按用户授权原样诊断。M08层覆盖通过不推翻质量失败；两套还改变了表面/核心尺寸，不能当单因素层数对比。

大网格审计应在大内存机器进行，内存预算包含xyz、全部面与连接、符号引用、临时数组及原生工程；顺序处理不同版本。保留输入哈希、独立质量报告和定位CSV，不调阈值掩盖失败。
