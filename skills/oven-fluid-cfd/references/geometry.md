# 几何清理、流体域与功能特征

## 范围先于布尔

在私有项目记录源文件哈希、单位、包围盒及实体/壳/面/边统计。历史初始装配包含薄壳，不能当作可直接相减的完整装配实体。先检查薄件自交、法向与内外空间。以真实内壁剖面/放样构建供风腔和风嘴包络，再逐件扣内部固体；直接用外包络相减可能把薄板外空气算进流体。

对入口、风嘴出口建立真实截面封盖；封盖后检查内部供风体的连通性。本例不包含中央敞开回风空间，后续仅补通供风侧连接段。新项目按实际流动路径与用户范围确定，不能自动扩大为回风全域。

## 特征取舍

| 特征 | 历史处理 | 复核方法 |
|---|---|---|
| 安装翻边、薄框、重复台阶、局部接管短过渡细节 | 按用户圈选删除或拉齐对流场影响小的非功能细节 | 前后局部截图、截面、净流道和体积变化；尺寸记录留在私有项目 |
| 风嘴喉口、喷缝、孔板通孔、V形嘴、供风孔 | 保留 | 真实截面、通孔几何签名与边界唯一覆盖 |
| 薄挡片及腰形孔 | 初版获准暂时省略自交件，后按新指令恢复真实轮廓和通孔 | 与源件轮廓、厚度及通流面积核对；不公开部件数量和尺寸 |
| 供风腔导流板 | 保留；仅拉齐非设计装配缝 | 板底/端部接触参照、自由尾缘与后方流道仍开放 |
| 上部过渡 | 按用户最终确认保留 | 防止仅因网格细就删除有意保留结构 |
| 供风侧连接段 | 按真实供风路径补通 | 截面与连通证据；不能将回风空间并入 |

去倒角应识别支撑面并延伸、求交、重建面，或在内壁截面阶段消除非功能性细节。`removeSplitter()`只能去冗余分割，不能替代去倒角。不能用大公差一把愈合喷缝和真实孔。

## 薄件重建与导流板接触

历史挡片原件存在深层自交。按真实二维轮廓拟合、保留腰形孔并按项目厚度挤出；轮廓偏差门槛由当前项目声明。核对真实外形和通流面积，不能用无孔矩形片代替。

导流板底部、端部的非设计装配缝可接到对应孔板或真实内壁；自由尾缘和有意保留的流道仍开放。按几何签名与流动路径判断，不照抄旧壳号、坐标或间隙尺寸，不能把所有小缝都封掉。

## 修复和独立验收

1. 每次修改新版本，在私有记录中登记特征位置、原尺寸、动作、理由、保护对象和前后截图。用户要求截图时，给真实CAD/网格视图并标明版本与切面；公开截图前另审查尺寸和结构数量。
2. ShapeFix/SameParameter或C0切分修复曲面参数时，同时约束公差、体积和外形；单纯`isValid`或减面数不构成通过。
3. 检查深层有效性、封闭实体、正体积和非流形边；连通组件与切面路径须符合当前供风范围。
4. 导出STEP/BREP后新进程独立回读；审计最短边、小面、通孔签名、挡片和连接段；保留可解释的小面，并作局部网格复核。
5. 实际转换到m后比较包围盒与体积。几何体积变化率是几何变动指标，不是压降误差、网格节省率或仿真精度。

只读工具：`<FreeCAD兼容Python> scripts/cad_audit.py --input <文件> --coordinate-units mm --expected-solids 1 --output <新报告.json>`。单位指内核回读后的坐标单位，需由项目已知尺寸确认；工具不会修改或自动缝合输入。命令中的实体数是单流体域适配器的准入要求，不是原装配结构数量。源装配阶段应单独审查，不能用流体实体准入标准掩盖其状态。
