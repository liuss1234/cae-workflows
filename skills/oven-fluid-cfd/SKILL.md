# 烘箱供风流体仿真

继承对话确定的域范围、保留特征、工况、计算地点和停止指令。先辨别用户要继续仿真、仅诊断还是整理技能；整理历史不能触发重新划网格或新求解。本技能支持从装配 CAD 到计算诊断及流量表，历史案例没有通过完整收敛验收。

## 不可混淆的工程约束

- 供风腔、供风连接、风嘴与中央敞开回风域分别定义；看到中间空腔不能自动全并入。补通应有截面和连通证据。
- 安装翻边、小倒角、装配间隙与真实节流孔、3 mm喷缝、孔板、导流板和挡片区别处理。暂时省略获准后，后续恢复指令优先；不能把省略60挡片固化成通用简化。
- 基本有效/封闭不能代替深层自交、曲面参数与独立STEP回读；`removeSplitter()`不是去倒角。重建必须保持真实轮廓与通孔。
- 面号只属于同一BREP和哈希；STEP重新导入后用位置、法向、面积、曲面类型和几何签名重新匹配。每个CAD湿面唯一归属。
- 网格节点实际为m，mm→m长度乘0.001、体积乘1e-9；检查包围盒和体积。完整NGON/NFACE保留命名与拓扑，不能偷换成四面体以绕过导入。
- “请求2层”与“实际2层面积覆盖”分别举证；孔壁、挡片、主壁、连接和导流板分组。层数少不证明y+合适或换热可用。
- 质量未通过只能保留原结论；用户授权诊断时单独记录原因、范围和网格哈希，不能改阈值伪造通过。不从两套多项参数不同的网格推断纯边界层效应。
- QFX保存后在新进程回读名称、归属、数量、尺寸、物性和持久化工况；设置完成不等于已求解。实际Linux CASE保存策略另查，不能把QFX的200步自动保存设置当成DG每200步写场。
- Slurm COMPLETED、正常写场、残差收敛、守恒、监控稳定和物理精度分别报告。停止请求优先；先保存停止，不擅自续算。结果不下载时只读取小型日志和统计。

## 工具入口

Python 3.8+；初始化、统计、宏渲染和合成自检只需标准库。FreeCAD审计、CGNS审计和QFlux分别使用兼容的独立环境，不向厂商Python盲装依赖。

```text
python scripts/oven_case.py init --output <新目录>
python scripts/oven_case.py validate --case <案例目录>
python scripts/render_star_macro.py --case <案例目录> --output <新目录>/MeshOven.java
python scripts/analyze_outlets.py --stage <求解阶段目录> --regions <regions.json> --density 1.2041 --window 100 --output <新统计目录>
python scripts/self_test.py
```

模板的网格尺寸仅为本次历史起点；新工况、单位和域范围留空，必须按项目填写。公开包不含客户CAD、SIM/CGNS/QFX/DAT、商业库、机器账号或连接凭据。
