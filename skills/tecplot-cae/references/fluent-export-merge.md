# Fluent 三维数据导出与合并

三维 Fluent 结果同时导出所有计算域、边界和截面，可能造成 Tecplot 数据量大、显示异常或加载变慢。一个更易检查的组织方式是分开导出体数据和表面数据。

## 流程

1. 第一次导出时不选择 Surfaces，选择需要的变量，输出只包含计算域体数据的文件，例如 `volume.plt`。
2. 第二次导出时选择需要的边界或自定义截面，取消流体域重复导出，保持变量选择一致，输出表面文件，例如 `surfaces.plt`。
3. 在 Tecplot 先打开体数据，再导入表面文件，并选择 `Append Data to Active Frame`。
4. 检查 Zone 名称、变量名、单位、坐标轴和边界位置是否一致，再开始切面或流线后处理。

二维数据可以按需要选择目标面直接导出，但仍应核对变量和单位。分开导出是数据组织策略，不是对原始求解结果的修复。
