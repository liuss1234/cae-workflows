# 网格与求解不稳定诊断

## 先区分阶段

查看实际日志、最后完整步、返回码、内存/磁盘和最近一次有效产物。终端没有新输出不等于挂起，DLL 诊断写到 stderr 也不必然失败。依据心跳、CPU、日志增长、产物完整性判断；若崩溃则保留失败阶段，不覆盖成功网格。

| 现象 | 先检查 | 可执行试验 |
|---|---|---|
| 导入少区/少边界 | CGNS单元类型、面段、名字、ZoneBC/接口侧面和单位 | 对照源计数及QFlux独立回读，修复导出器 |
| 首步速度/湍流量异常 | 压力口径、介质、MRF轴/旋向、壁面参考系、接口连通、初始 k/epsilon | 小步预运行，定位超限位置与流向 |
| 多步后 continuity/k 发散 | 负体积、低质量单元、无层或层过薄、接口/开口回流 | 先修几何和网格，再单因素调整数值 |
| 调低松弛仍发散 | 是否实际生效，是否同一来源网格/初值，运行是否读旧QFX | 回读工况并比较配置哈希，保留失败证据 |
| 优化工具异常退出 | 候选是否真的生成，单元/网格hash是否改变 | 原件保留，候选完整回读后才替换 |
| 保存中断/文件截断 | 剩余空间、多个副本和staging占用 | 新路径重新保存，原子落盘后独立打开并验证 |

## 有记录地逐项试验

先保存基线、网格/QFX 哈希与初值。需要时从稳健格式/松弛开始；每阶段明确改动和停止条件。更改多个量时只能视为组合试验，不能宣称已经确定单个原因。

“一阶格式”“降松弛”“非正交修正次数”“非正交限制开关”“速度上限”和“correctFlux”分别记录。只设置一项不能描述为全部试过。

- 非正交：记录实际最大角度及位置、修正次数、限制值/开关、通量修正开关；更多修正不保证修复近退化网格。
- 速度限制：先由旋转叶尖速度 `Utip=pi*D*rpm/60` 与局部流动物理确定候选限制，记录触发次数、比例与位置；不把 `Utip` 当全场绝对物理上限。限制长期大量触发时，不能将稳定残差解释为有效解。
- 层网格：无棱柱层需明确说明；可适当增加目标厚度，但先检查微间隙、偏移自交及实际缩薄。请求 0.3 mm 而实际 0.05 mm 必须按实测交付。
- 得到稳定候选后，检查取消/提高限制、升级格式和网格调整的敏感性，才能判断性能是否依赖数值限制。

诊断表至少包含阶段、网格/QFX hash、实际设置、起止步、残差极值、流量波动、质量不平衡、限制触发统计、终止原因和最终场。NaN、未达要求步数或大质量不守恒阶段可用于诊断，不能纳入有效性能排名。
