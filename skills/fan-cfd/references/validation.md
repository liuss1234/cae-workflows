## 可自行复现的安装检查

普通Python安装NumPy，提供目标CGNS动态库的真实路径及正确的cgsize整数位宽：

```text
python scripts/create_smoke_case.py --output <新目录> --library <CGNS动态库> --cgsize-bytes <4或8>
python scripts/fan_case.py check-mesh --case <目录> --evidence <目录>/checks/mesh_evidence.json
<厂商匹配Python> scripts/qflux_adapter.py setup --case <目录> --qflux-home <安装目录>
<厂商匹配Python> scripts/qflux_adapter.py readback --case <目录> --qflux-home <安装目录>
```

生成器使用精确方块的体积、正交性和结构化行数作为安装证据。它没有叶片，不验证真实风机棱柱层生成、壁面y+、空气动力学或收敛；不要把合成层覆盖用于产品报告。

完整仓库检查在本轮Windows/Python3.11通过：59个Python/宏文件、9个JSON、7个YAML、6个技能入口、78个相对链接、37个命令行帮助，以及初始化保护、两套风扇自检、六个安装包CRC/逐文件SHA256。

## 未覆盖的范围

- 几何清理与STAR/Gmsh建网格方法来自既有案例经验，本轮没有重新进行客户几何清理、大型网格划分、500步复算或网格无关性研究。
- 通用证据准入核对实际报告，不自行计算全部网格质量；原生/独立拓扑、形状、层自交、y+和接口相容性仍需验证。
- 适配器限说明中的单转子等温稳态模型；其他湍流模型、多个转子、滑移/瞬态、热耦合及其他边界需单独扩展。速度上限及通量/非正交限制开关没有被内置脚本暗设。
- 普通Python为Windows/Linux可迁移代码；本轮商业API及CGNS C库仅Windows实测。GitHub Actions配置的两平台检查不等于两平台商业软件验证。
- 线性混合导出器不包含NGON/NFACE多面体，STAR多面体使用原生导出后验收。用户目标模型应核对实际全部类型，不能按文件扩展名推定兼容。

仓库 `tools/check_repository.py` 执行源码/元数据/文档链接/命令行/自检和ZIP CRC/SHA256验证；不自动重新运行上述商业链路。具体提交的CI结果以GitHub实际记录为准。
