# STAR / Gmsh 网格与实际边界层

## 参数计划

先明确是 STAR 多面体、Gmsh 四面体/棱柱混合，还是用户要求的结构化网格。STAR 多面体与 Gmsh 四面体对比只说明指定两套网格和算法组合的差异；不能将差异全部归因于求解器。Gmsh 不自动等价生成 STAR 多面体。

| 参数 | 记录口径 |
|---|---|
| 体网格 | 基础尺寸、最小/最大尺寸、增长率及体积控制区 |
| 局部细化 | 叶片前后缘、叶尖间隙、静叶、尾迹和接口；说明依据 |
| 进出口 | 与近场合理过渡，避免过稀及无物理理由的远场细化 |
| 层网格 | 每组壁面请求层数、首层或总厚度、增长率、局部缩薄/减层条件 |
| 壁面处理 | 湍流模型、壁函数与目标 y+ 的相容性；求解后核验实际 y+ |
| 验收 | 非正体积/无效拓扑数、体积误差、非正交、形状质量分布、层覆盖及最差位置 |

若用户指定风扇/外框/静叶 5 层、其余壁面 2 层，则只在该案例继承；首层高度或总厚度需结合 y+、间隙和层碰撞确定。允许小角度局部减层时，优先保持有效体积和连续过渡，明确实际生成结果。

总厚度为 `H=h1*sum(r**i, i=0..n-1)`；`r=1` 时为 `n*h1`。模板允许填写首层或总厚度；同时填写必须一致。请求厚度与实际中位厚度分别记录，不能以设置值代替实测。

## STAR 分支

使用独立 `.sim` 工作副本，确认导入的米制坐标和命名表面。表面修复/包裹若改变间隙或叶型，需做形状对照后再建体网格。选择目标版本支持的表面重构、多面体、棱柱层模型，按边界组分配层数与厚度，不对压力开口铺壁面层。

宏与 API 随版本变化，先用小型合成通道验证导入、模型选择、局部控制、实际层场与 CGNS 导出，再运行产品模型。本技能提供参数与检查工具，不附一个冒充所有版本通用的 STAR 宏。

输出原生质量报告、各区域单元数/体积、Prism Layer Number / First Prism Layer Height 等实际场。采样与壁面面中心对应，按面积统计 0/1/.../n 层及缩薄，记录未匹配面积。只看总棱柱数量不能证明叶片各壁面有层。

## Gmsh 分支

OCC 中导入已验收流体实体并 fragment，共形接触面共享；按几何来源和邻接关系建立 Physical Volumes / Surfaces，保存 `physical_names.json`。不要用不稳定的导入面序号长期代表叶片。

选择以下实际可用方法：外部/离散三角面法向棱柱挤出并填充核心、Gmsh 版本支持的三维层算法、或先构建分块后生成有结构层。Gmsh 的二维 BoundaryLayer 场不能直接当任意三维叶片的棱柱层。无法稳定产生所需层时，应说明限制并调整方案，不能静默退为纯四面体后称完成。

法向挤出前先统一封闭三角壳朝向，检查非流形、重叠和翻面，再验证流体侧法向。CAD orientation 与 MSH 面 orientation 需要实测，不能直接相乘推定。按局部间隙/曲率限制高度，检查偏移壳相交、相邻层交叠、核心壳闭合，再填充核心并建立棱柱/四棱锥过渡。

正 Jacobian/正体积不能证明偏移壳无自交。薄层的低形状指标需结合长宽比、非正交、真实层厚和 y+ 判断；仍需定位最差单元。Netgen 等优化异常退出时，保留原网格哈希，不声称失败优化产生了新网格。

## 米制导出与验收

导出前明确一次长度转换，体积按比例三次方、面积按平方变化。CGNS 导出支持必须覆盖实际所有单元类型；不支持的棱柱/四棱锥/多面体要停止并适配。逐区核对：节点、各类型单元、总体积、边界面数/面积、接口两侧、包围盒和名称。

`fan_case.py check-mesh` 接受与网格 SHA256 绑定的统一实测 JSON，格式见 [schema](scripts-and-schema.md)。它重算面积覆盖与门槛，只是证据准入工具；需由 STAR/Gmsh/独立拓扑检查实际产生输入。它不计算所有网格质量，也不自签“网格合格”。

最终在 QFlux 中导入、保存、新进程回读全部区与边界名称、所属区、面数和米制包围盒。纯网格 QFX 没有 motion/interfaceGroup 时只可交付为网格阶段，不能称 MRF 就绪。
